# PDF 추출 · 점역 규칙

이 코드베이스만의 관례. 최종 정합 척도는 **BRF ASCII 셀 비교**이다 ([architecture.md](architecture.md)).  
역점역은 검수용이며 정방향과 대칭이 아니다 ([reverse_translation.md](reverse_translation.md)).

| 구분 | 코드 |
|------|------|
| PDF | `pdf/extractor.py` 외 `pdf/` |
| 점역 | `braille/translator.py`, `common/korean_tables.py`, `common/hanja_reading.py` |
| 레이아웃 | `layout/engine.py` |

# 1. PDF 추출

## 1.1 파이프라인 (요약)

```text
문서: infer_layout_profile (머리/꼬리·2단)
면마다:
  span 추출 → 표/그림/밑줄/꺾쇠 → 줄(build_lines)
  → 병렬 선택지(고신뢰만) → 중략 줄거리 → 그래픽 선형화
  → ※ 정규화 → 블록 → 측면 마커 → reading order → 후보 태그
```

진입점: `extract_pdf` → `build_page_structure`.  
이후 Exam 빌드·점역·32×26 레이아웃은 [architecture.md](architecture.md).

## 1.2 특별 예외·상황

일반 글자 줄이 아닌, **따로 다루는 객체·상황**만 열거한다. 확신이 없으면 승격하지 않고 기존 reading order를 유지한다.

| 예외 | 무엇이 특별한가 |
|------|----------------|
| **2단·머리/꼬리** | 스트림 순서가 아니라 좌표 밴드·거터로 재배치. 거터 실패 시 면마다 cut (`page_local`). |
| **줄 묶음** | `y_mid`로 같은 시각 줄. 글자 크기만 다른 span을 가로 gap으로 쪼개지 않음. |
| **벡터 표** | 도면 격자로 복원 후 행 텍스트로 승격. 앞·뒤만 `─` 표선. |
| **래스터 그림** | OCR 없음 → `[그림]` 자리표시. 범례·겹침 글자 생략. 글자 과다(노트형)면 `[그림]` 생략·글자 유지. |
| **밑줄** | 폰트 플래그가 아니라 짧은 가로 벡터선 ∩ 글자 → `<u>…</u>`. |
| **지문 `[A]`~`[E]`** | 여백 꺾쇠 기하 검출. 여백 인쇄 표지만 삭제(본문 `[A]의…` 유지). 라벨이 바뀌면 블록 분할. |
| **병렬 선택지 ①×㉠/㉡** | 반복 x-lane + ①~⑤ + **열 헤더 필수**일 때만 `① ㉠ … / ㉡ …`로 재조합. 헤더 없는 선택지\|지문 2단은 승격 안 함. |
| **측면 마커** | 오른쪽 마커만 있는 짧은 ①~⑤ 등을 왼쪽 다행 질문 끝에 붙임. 본문 있는 선택지·장문 Passage는 제외. |
| **중략 줄거리** | 표지 행부터 같은 글꼴 런 끝에 `[줄거리 끝]` 삽입. |
| **원문자 전용 행** | 라벨만 있는 ⓐⓑ… 행 병합. 본문 인라인 `ⓐ<u>…</u>`는 유지. |
| **큰 박스** | 닫힌 큰 프레임에 `─` 표선 행. 짧은 `[가]`형 빈칸 박스는 표선 생략. |
| **※** | 같은 줄이면 앞에 줄바꿈 (`text_normalize`). |
| **불투명 글리프** | `/`로 치환. 길이 바뀌면 `char_bboxes` 포기(글자 단위 밑줄 후퇴). |

# 2. 점역 — 처리 순서

문자열(또는 Exam 노드 `raw_text`)이 들어오면 아래에서 위 순서로 적용한다.  
핵심 진입점: `hangul_text_to_ascii` / `TableBrailleTranslator.translate_node`.

## 2.1 Exam 노드 전처리 (`translate_node`)

1. **Header** — 전용 패딩·가운데 정렬 ASCII (`preformatted`).
2. **Footer** — 숫자만 있으면 본문 점역에서 생략.
3. **※** — `ensure_newline_before_reference_mark`.
4. **개행** — Passage/Choice/Question 이고 시가 아니면 `\n` → 공백. 다만 `\n※`는 유지.
5. **시** (`indent_genre=시`) — 하드 개행 유지 → 레이아웃에 `keep_hard_newlines`.
6. 지문 꺾쇠 시작/끝 라벨을 시퀀스 메타로 전달 (레이아웃이 `┌────` 등).
7. → `translate_text` (= `hangul_text_to_ascii_with_roman_mask`).

## 2.2 문자열 전처리 (`hangul_text_to_ascii_with_roman_mask`)

1. 불투명 코드포인트 → `/` (`opaque_text`).
2. 한자 → 음독 한글·병기 접기 (`hanja_reading`).
3. 연속 `·` 4개 이상 → `····`.
4. ※ 앞 줄바꿈 (아직이면).
5. `\n`으로 줄 분리 후 **줄 단위** 점역. 줄 사이 ASCII `\n` 유지.

## 2.3 줄 단위 — 고정·구조 토큰 먼저

줄 전체가 아래면 일반 음절 루프를 타지 않는다.

| 조건 | 결과 |
|------|------|
| `[그림]` | 고정 그림 생략 ASCII |
| `[줄거리 끝]` | 고정 ASCII |
| `────` 등 표선 행 | `!333…4` 류 |

그다음 `<u>…</u>`를 찾아 본문 / 강조를 갈라 끼운다.

- 본문 → §2.4
- 구간마다 앞 `,-` · 뒤 `-'`

한 줄 안에서 또:

1. 줄 시작 `N.` 문항번호 → 수표+숫자+`4 `
2. `[1~3]` 형 지문 범위 → `82#a\`9#c;0` 관례
3. 나머지 → §2.4 본문 루프

## 2.4 본문 문자 루프 (`_hangul_body_to_ascii_masked`)

왼쪽부터 한 번에 하나씩(또는 런 단위). 우선순위 대략:

1. 공백  
2. 단어 약어 표 (`그래서` 등)  
3. 숨김표 런 (○ / □ / △ / ✕)  
4. `→` → `/화살표/` 셀열  
5. 원문자 ①–⑤ · ⓐ–ⓩ · ㉠–㉭ · ㉮–㉻  
6. **숫자** 런 → 수표 `#` + 숫자. 뒤가 한글·라틴이면 보통 공백(대괄호 점수·붙는 구두 예외).  
7. **로마자** 구간 → `0` + 글자(대문자마다 `,`) … 끝나면 비로마 앞 `4`  
8. **한글 음절** → `_encode_syllable` (약자·것·가류·웠/혔·예 붙임줄 등)  
9. 수식 `+−×÷=₩$` → `#`+본문. `<>`·`-`는 **숫자 옆일 때만** 수식.  
10. 구두점·줄임표·가운뎃점·괄호 등 (`_PUNCT_TO_ASCII`)  
11. 호환자모 → 온표+초성 또는 `=?`  
12. 그 외 건너뜀

음절 인코딩 요지: 것 약자 · VC/CV 약자 · 혔 계열(초성+`-`+ㅕ+ㅆ) · 가류+ㅆ는 약자+`/` 금지 → 초성+ㅏ+ㅆ · 일반 초·중·종.

## 2.5 레이아웃 (점역 직후)

- 산문 Passage 등: 남은 `\n` 평탄 후 32셀 soft wrap. **`\\n99`(※)** 는 유지.
- 시: 하드 개행 유지·행별 wrap.
- 로마 `roman_mask`: 이어지는 줄이 영어인데 `0`이 없으면 앞에 `0` 재삽입.
- `→` 셀열은 줄 중간에서 끊지 않음.

# 3. 점역 — 예외 케이스 (분류)

순서표에 안 드러나는 **충돌·특수 관례**만 모은다.

## 3.1 같은 셀 충돌

| 상황 | 규칙 | 예 |
|------|------|-----|
| `.` ↔ 종성 ㅍ (`4`) | 어절 ≤2음절이면 `.` 앞 공백 | `가.` → `$ 4` |
| `?` ↔ 종성 ㅌ (`8`) | 동일 | `가?` → `$ 8`, `햇볕`=`jr'^:8` |
| `!` ↔ 종성 ㅋ (`6`) | 동일 | `가!` → `$ 6` |
| `<` ↔ ㅇ+`(` | `<`=`78`, `(` 앞 ㅇ은 `78'` | `장(` |
| `…`/`...` vs `⋯`/`···` | 마침표형 `444`(앞 공백) · 가운뎃점형 `,,,` | |
| `·` | `"2` (구 `1;` 금지 — `일치`와 충돌) | |
| `∙` | `"4`+공백 | |
| `/` | 빗금은 `_/` (단독 `/`는 ㅖ·ㅆ) | |
| `ㄹ.` | 단독 `="4` (음절 안 `14`는 ㄿ) | |

## 3.2 로마자

| 규칙 | 예 |
|------|-----|
| 구간 시작 `0`, 대문자 `,`+소문자 | `FOB` → `0,f,o,b` |
| 뒤가 비로마면 종료표 `4` (문자열 끝만 로마면 생략) | `LA항` → `,l,a4j7` |
| 영문 안 공백·`()`·`,`(뒤 라틴)은 같은 로마 구간 | `Cost, Insurance` |
| soft wrap 시 이어지는 영어 줄에 `0` 재삽입 | |

## 3.3 원문자·숨김표

| 묵자 | 점역 |
|------|------|
| ①–⑤ | `7#a7`…`7#e7` |
| ⓐ–ⓩ | `7a7`… (`70a7`/`‘a’` 아님) |
| ㉠–㉭ | `7=@7`… (온표+초성) |
| ㉮–㉻ | `7$7`… (음절) |
| ○×n | `_`+`0`×n+`l` |
| □×n | `_`+`7`×n+`l` |
| △ / ✕ | `_+l` / `_xl` |

밑줄은 인라인 `ⓐ,-…-'` 유지. 향찰용 2줄 분리 특례 없음.

## 3.4 한자

| 형태 | 규칙 |
|------|------|
| 한자 단독 | 음독 한글로 |
| 한글(한자) | 음 같으면(두음법칙 동등) 한자 생략 |
| 한자(한글) | **완전 일치**만 생략 |
| 사전 없음 | `/` |

한자 전환 표(`0` 전치)는 쓰지 않음.

## 3.5 온표 · 약자 · 붙임줄

| 주제 | 규칙 | 예 |
|------|------|-----|
| 온표 | 단독 자모 `=`+초성(2017) | `=e` → ㅁ |
| 옹 | `=` 직후가 모음·VC면 온표가 아니라 옹 | `옹호`=`=ju` |
| 하였 vs 혔 | `j:/` = 하+였 · `j-:/` = 혔 | |
| 예 | 무받침 음절 뒤 `예` 앞에 `-` | `유예`=`%-/` · `예정`=`/` |
| 가류+ㅆ | 약자+/ 금지 → 초성+ㅏ+ㅆ | `팠`=`d</` |

## 3.6 수표·수식

| 묵자 | ASCII |
|------|--------|
| 숫자 | `#` + `a`–`j` |
| + − × ÷ = | `#5` `#9` `#*` `#//` `#33` |
| <> | 숫자 옆만 `#99`/`#55`, 아니면 각도괄호 `78`/`07` |
| ₩ $ | `#0@w` `/` `#0@s` |
| `#5` | **더하기** (원문자 ⑤는 `7#e7`) |

## 3.7 시험지·레이아웃 토큰

| 대상 | 규칙 |
|------|------|
| `[1~3]` | `82#…\`9#…;0` |
| `→` | `/화살표/` 셀열, 줄바꿈 시 비분리 |
| ※ | `99`, 앞 줄바꿈·Passage flatten에서도 `\n99` 유지 |
| `[그림]` / `[줄거리 끝]` / `────` | 고정·표선 ASCII |
| 구간 `[A]` | 메타 → 점역 `┌────` 표지 행 |
| Footer 숫자만 | 생략 |

## 3.8 Passage 개행·장르 (Exam 이후)

| 대상 | 개행 |
|------|------|
| 산문 Passage / Choice / Question | 하드 개행 → 공백 (※ 제외) |
| Passage 시 | 시행 유지 |
| Header 등 preformatted | 줄 단위 |

장르 판정 순서(들여쓰기): 대화문(쌍점 ≥5) → 시 → 소설 → 비문학. 대화문은 내어쓰기뿐 아니라 **연속 L 대사**도 새 문단.
